# Task 1: Linear Regression

We use a linear model:

$$
y = w_0 + w_1 x + \varepsilon
$$

```python
import numpy as np
from sklearn.linear_model import LinearRegression

X = np.array([[1], [2], [3]])
y = np.array([2, 4, 6])
model = LinearRegression().fit(X, y)
print(model.coef_)
```
